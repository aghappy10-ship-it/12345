# 快照与运行条件

这是一份独立源码展示快照，来自活动工程 `x2d2-reference-restart`。没有修改活动工程冻结的正式源码，没有复制或修改旧 `x2d2` / `x2d2-codex-independent` 工程。

**本页仅描述首批263文件阅读快照，不是全量资产排除规则。** 用户随后要求全部工程资产，因此原厂材料、镜像、依赖和研究日志等改由私有Release保存，范围见[完整资产说明](FULL_ASSETS.md)。旧工程只读压缩，不制作展开副本；真实照片及明确的运行会话令牌仍排除。

## 纳入

- 当前原创 / 已声明许可的原生、QML、构建、部署衔接、恢复、测试和工作台源码，按字节保留。
- 当前正式永久回归登记与原计划的选定快照，标为历史记录。
- 最新修正草稿和选定既有本地控制结果；它们仍是未合并或未执行状态，不是安装包。
- 中文成果地图、真实状态、教训和参考来源。

## 能否直接运行

本地网页服务入口为：

```text
python -B devtools/app.py
```

服务自身使用Python标准库，但源码快照没有进行全新环境启动验收。启动服务不等于所有模块可用：

| 功能 | 另需条件 |
| --- | --- |
| 桌面Qt原厂预览 | 本地Qt6.8.2、原厂GUI提取素材、宿主桥和构建产物 |
| 原厂代码浏览 | 旧工程里保留的合法原厂研究材料，不在首批源码树；完整资产Release中保留 |
| 当前审计显示 | `app.py`仍固定引用既有20261007-host-model路径；没有此目录时不能显示当前完整检查 |
| 机内读取 | 既有固定传输源和真实连接；USB识别成功不是通道成功 |
| 完整回归 | 精确原厂输入、旧352目标种子和既有环境，未随本快照公开 |
| Codex插件 | 插件清单仍包含原电脑路径，需要配置本机解释器与源路径；本次没有安装或发布插件 |
| 相机部署 | 适用发布要求、当前实机验收和用户最终批准；本仓库没有授予这些条件 |

原有 `Launch.cmd`、插件和工具中保留了精确本机路径，避免改变源码字节造成旧证据错绑。目录可阅读，但不能宣传为任意电脑一键安装 / 上机版本。

`SNAPSHOT_MANIFEST.json`列出导出文件及SHA256，以及选定既有结果的源身份。导出前后源码逐项哈希对照；不靠文件名的green / pass推定测试成功。

这次只检查上传范围、文件一致性、敏感内容和文档引用，没有重跑固件测试，也没有生成相机安装包。Git提交证明源码快照已保存；GitHub读回才证明实际远端提交，二者分开报告。
