# Publication snapshot rules

- This repository is a research/source snapshot, not an installable firmware release.
- Keep original-source files byte-exact and separate proposed drafts from formal code.
- Historical test results belong to their recorded input hashes; do not claim they verify new code or live hardware.
- No automatic camera access, deployment, flashing, calibration, or photo changes.
- For documentation/publication work, validate its contents and links. Do not launch firmware audits merely to publish documentation.
- Preserve failure history, official recovery requirements and third-party notices.
- The originating project's current feature is menu entry/page/back, boot loading and withdrawal, with stock capture layers retained. Burst/AF changes are out of scope for that candidate.
